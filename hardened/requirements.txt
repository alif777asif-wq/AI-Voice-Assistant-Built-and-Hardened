# ---------------------------------------------------------------------
# IMPORTANT: openwakeword is installed as a SEPARATE step, not via this
# file, on both Linux and Windows:
#
#   pip install --no-deps "openwakeword>=0.6.0"
#
# Why: the current PyPI release of openwakeword unconditionally declares
# a dependency on `tflite-runtime` when installing on *Linux* (no such
# marker applies on Windows), even though this project only ever uses
# openwakeword's ONNX Runtime backend (see src/l_assistant/wake/wake_word.py for
# why ONNX is pinned on both OSes). As of this writing, `tflite-runtime`
# has no installable distribution on PyPI at all for current Python
# versions -- a plain `pip install openwakeword` therefore fails outright
# on Linux. openwakeword does not actually import tflite at all unless
# you explicitly request the tflite backend, so `--no-deps` (combined
# with the real dependencies already listed above) is the correct,
# minimal fix rather than a fragile workaround -- and it's applied on
# both OSes for consistency, even though Windows was never actually
# broken. `scripts/setup_linux.sh` and `scripts/setup_windows.ps1` both
# run this step automatically.
# ---------------------------------------------------------------------
